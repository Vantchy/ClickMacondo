## 一、系统架构总览

```
┌─────────────────────────────────────────────────────────┐
│                    双轴体系 (Dual Axis)                    │
│  ⭐ 宿命值 (fateCounter)  ←→  🤝 羁绊值 (bondCounter)     │
│  每章 0-6，章末结算烙印，动量传递下章起始值                   │
├─────────────────────────────────────────────────────────┤
│                    四象限 (Quadrants)                     │
│  家族守望者(高F+高B) │ 孤绝先知(高F+低B)                    │
│  命运追随者(低F+高B) │ 孤独反抗者(低F+低B)                   │
├─────────────────────────────────────────────────────────┤
│                  三层宿命 (Three-Layer Fate)              │
│  L1 章节值 → L2 烙印(永久) → L3 动量(惯性传递)              │
├─────────────────────────────────────────────────────────┤
│                  四层因果 (Four-Layer Causality)           │
│  A.标记累积+阈值门 │ B.场景变体 │ C.回声文本 │ D.隐藏线索      │
└─────────────────────────────────────────────────────────┘

结局判定：按 fateImprint/bondImprint 统计 → 7种结局(4象限+反抗者烙印+均衡烙印+全线索)
```

## 二、数据字段速查

### choice.effects 完整字段
| 字段 | 类型 | 说明 |
|------|------|------|
| `tags` | string[] | 标签（跨章追踪用） |
| `memory` | string\|null | 解锁的记忆碎片 ID |
| `fate` | number | 宿命值变化 (-2 ~ +2) |
| `bond` | number | 羁绊值变化 (-2 ~ +2) |
| `relationshipEffects` | {name: delta} | 角色关系值变化 |
| `characterFlags` | {flag: count} | 跨章标记累积 |
| `clue` | string | 获得的线索道具 ID |
| `targetChapter` | number | 序章专用：跳转目标章 |
| `emotionalCost` | string | (v2.0 保留在数据中，UI 不渲染) |
| `alternativeNarrative` | string | 羊皮卷的另一页 |
| `requiredMemory` | string | 需要持有该碎片才可见 |
| `requiredClue` | string | 需要持有该线索才可见 |
| `requiredFlag` | {flag, min} | 需要达到标记阈值才可见 |

### scene 完整字段
| 字段 | 说明 |
|------|------|
| `leftPage.clues[]` | 隐藏线索定义 `{triggerText, itemId, narrative, unlocksIn}` |
| `echoText` | 回声文本（条件触发） |
| `echoCondition` | 回声触发条件 `{flag, min}` / `{memory}` / `{clue}` |
| `marginalia` | 边缘文字 `{text, style}` |
| `mood` | 角色情绪状态 |
| `settlement.quadrantNarratives` | 四象限情感结算文本 |

## 八、数值体系参考

### 双轴最大值
```
MAX_FATE = 6, MAX_BOND = 6
```

### 烙印判定 (每章结束时)
```
宿命烙印: 抗争者(≤2) / 追随者(3-4) / 见证者(5-6)
羁绊烙印: 疏离者(≤2) / 羁绊者(3-4) / 家族的魂(5-6)
```

### 动量传递 (下章起始值)
```
见证者 → 起始 fate = 4 (2/3 × 6)
追随者 → 起始 fate = 2 (1/3 × 6)
抗争者 → 起始 fate = 0

家族的魂 → 起始 bond = 4
羁绊者   → 起始 bond = 2
疏离者   → 起始 bond = 0
```

### 四象限
```
        高 bond ↑
  命运追随者  │  家族守望者
  (低F+高B)   │  (高F+高B)
  ────────────┼────────────→ 高 fate
  孤独反抗者  │  孤绝先知
  (低F+低B)   │  (高F+低B)
        低 bond ↓
```
