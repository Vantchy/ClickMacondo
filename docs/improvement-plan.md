# 《百年孤独 · 宿命之环》改进计划

> 基于全系统分支完整性审计结果，按优先级排列。
> 原则：优先选择"引擎就绪、只缺数据"的改进，其次选择"引擎需少量改动"的改进。

### 1.2 结算页渲染象限叙事（quadrantNarratives）

**现状**：每个结算页的 `settlement` 对象已经包含了 `quadrantNarratives` 数据（guardian/prophet/follower/rebel 四种），但 renderer 从未渲染它们。数据已填好，只差渲染器的一行调用。

**效果**：每轮结算时，玩家会看到一段基于当前象限的个性化叙事。这让 fate/bond 值在每一章都有即时反馈。

**方案**：在 renderer.js 的结算渲染逻辑中，读取 `st.quadrantNarratives` 并渲染当前象限对应的段落。

**涉及文件**：`frontend/src/core/renderer.js`（约 +10 行）

**引擎修改**：约 10 行。

### 1.3 隐藏选项灰位提示

**现状**：当玩家缺少所需线索/记忆时，`filterChoicesByMemories` 会直接隐藏该选项。玩家看到 3 个选项，不知道有第 4 个被藏起来了。

**效果**：在选项列表中显示一个灰掉的"？？？"位，提示有隐藏内容等待发现。这是"线索猎人"成就的前置引导。

**方案**：renderer 渲染选项列表时，对比原始选项数量和过滤后数量。如果少了，在列表末尾追加一个灰位提示。

```html
<div class="choice-btn choice-locked-hint">
  <span class="choice-label">？？？</span>
  <span class="choice-desc">—— 需要特定的线索或记忆才能解锁此选项 ——</span>
</div>
```

**涉及文件**：`frontend/src/core/renderer.js`（约 +8 行）

**引擎修改**：约 8 行。

### 2.3 关系值门控支持（引擎 +10 行）

**现状**：关系值可以积累（`adjustRelationship`），也有档位判定（`getRelationshipTier`），但没有选项被关系值门控。引擎 `filterChoicesByMemories` 不支持关系值条件。

**效果**：与特定角色建立深厚关系后，在关键时刻多出一个选项——"因为你了解她/他，所以你知道该说什么。"

**方案**：

**引擎层**：在 `filterChoicesByMemories` 中添加关系值条件判断（+10 行）。

```js
// game-engine.js filterChoicesByMemories 中添加
if (choice.requiredRelationship) {
  const { character, min } = choice.requiredRelationship;
  if ((GameState.relationships[character] || 0) < min) return false;
}
```

**数据层**：在 3-5 个关键场景添加关系门控选项。

| 章节 | 选项 | 条件 |
|------|------|------|
| Ch5 R3 | "你知道乌尔苏拉会怎么安慰你——回家" | 乌尔苏拉 ≥ 70 |
| Ch12 R4 | "你被乌尔苏拉爱过——你知道怎么告别" | 乌尔苏拉 ≥ 85 |
| Ch17 R3 | "你知道阿玛兰妲·乌尔苏拉的恐惧——因为你也怕" | 阿玛兰妲·乌尔苏拉 ≥ 60 |

**涉及文件**：`frontend/src/core/game-engine.js`（+10 行），`chapters-data-2.js`, `chapters-data-4.js`, `chapters-data-5.js`

### 2.4 记忆碎片收集回响（结算页展示）

**现状**：获得记忆碎片后只是静默加入数组，结算页不提及。玩家可能在几章后才在历史档案中发现"哦我得了那个碎片"。

**效果**：每轮结算时显示本轮获得的记忆碎片标题，让收集有即时仪式感。

**方案**：在 renderer.js 的结算渲染中，检查本轮选择的 `effects.memory`，如果有值则渲染一行：

```html
<div class="settlement-memory">◆ 获得记忆碎片：「覆手」</div>
```

**涉及文件**：`frontend/src/core/renderer.js`（约 +5 行）

### 2.5 标签倾向总结（个人简介）

**现状**：个人简介展示标签列表和分章进度，字多但无总结。

**效果**：在简介顶部生成一段 2-3 句的自动总结，基于玩家标签倾向。

**方案**：在 `SidebarManager.openProfile()` 中，分析 `GameState.tags` 中最频繁的 5 个标签类别，生成文本。

```
"在马孔多的这些年里，你倾向于把家人放在第一位，但你的好奇心经常把你拉向未知。
你与命运的关系是：有时顺从，更多时候是并肩而行——偶尔推它一把。"
```

用简单的关键词 → 倾向映射即可。

**涉及文件**：`frontend/src/ui/sidebar.js`（约 +30 行）
