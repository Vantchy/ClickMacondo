## 文档阅读顺序

### 用户 / 玩家
1. `README.md` — 了解项目概况、如何运行

### 开发者（快速上手）
1. `README.md` — 项目结构和快速开始
2. `doc-instruction/CODE_EXPLANATION_circle-of-fate.md` — 代码逐模块详解
3. `doc-instruction/ARCHITECTURE_circle-of-fate.md` — 架构全景图与依赖关系

### 策划 / 设计师
1. `Story-ideas/project-spec.md` — 核心诊断与增强方向
2. `Story-ideas/manual.md` — 设计总纲与因果体系
3. `Story-ideas/implementation-guide.md` — 具体实施步骤

### 修改代码时的速查
- 改入口页 → `index.html`
- 改剧情 → `assets/data/chapters-data*.js`
- 改逻辑 → `src/core/game-engine.js`
- 改渲染 → `src/core/renderer.js`
- 改UI → `src/ui/ui.js`
- 改样式 → `styles/styles.css`
- 改常量 → `src/utils/config.js`
- 改音效 → `src/utils/sfx.js`
- 改存档 → `src/utils/storage.js`
- 调试跳转 → `src/utils/debug-panel.js`（仅破解版）

## 正式版 vs 破解版

| 差异 | 正式版 | 破解版 |
|------|--------|--------|
| 入口文件 | `circle-of-fate.html` | `circle-of-fate-unlock.html` |
| 进度条拖动范围 | 仅可拖到已访问位置 | 全书任意位置 |
| 章节跳转面板 | ❌ | ✅（Ctrl+Shift+D） |
| 左上角章节名可点击 | ❌ | ✅ |
| `debugJump(n)` 命令 | ❌ | ✅ |
| 额外 JS 模块 | — | `debug-panel.js` (328行) |
| `__IS_DEBUG__` 标志 | `false` / 未定义 | `true` |
