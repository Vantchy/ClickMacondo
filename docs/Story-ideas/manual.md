# 《百年孤独·宿命之环》行动指南

> **文档定位**：综合设计决策、系统架构、逐章因果链、实施路线。
> **不含代码**——仅描述设计意图、数据结构、因果逻辑、优先级。
> **版本**：v2.0（基于双轴+烙印+线索+回声四层因果体系）

---

## 一、设计总纲

### 1.1 核心命题

> **让玩家感到"被命运推着走"——数值有质变，选择有惯性，过去的选择在未来的叙事中回响。**

### 1.2 六条设计原则

| # | 原则 | 说明 |
|---|------|------|
| 1 | **不剧透** | 选项上不展示代价标签。后果在叙事中自然浮现，事后在结算中回响 |
| 2 | **数值有质变** | 每个数值跨过阈值时有可见的叙事变化——不是"数字变了"，是"故事变了" |
| 3 | **选择有惯性** | 上章的选择影响下章的起点。不是锁死，是倾向——你可以转向，但要用力 |
| 4 | **因果有回响** | 每章插入 1-2 句"你记得……"，让过去的选择在当下的叙事中闪现 |
| 5 | **发现而非告知** | 隐藏线索藏在文本颜色中；象限变化在叙事语气中体现；关系变化在对话中流露 |
| 6 | **成本可控** | 用标记累积+阈值门替代指数级分支；桥接章只加回声和线索，不加场景变体 |

### 1.3 四层因果体系

```
A. 标记累积 + 阈值门（骨架）
   → 跨章累积标志，在 5 个关卡章检查阈值触发变体
   → 覆盖：全部 22 章（桥接章积累，关卡章触发）

B. 场景变体（血肉）
   → 同一场景写 2-3 个版本（仅关键章 30-50% 场景）
   → 覆盖：6 个核心章（5/10/12/17 + 1/2/3/8/11/19 部分）

C. 回声文本（肌理）
   → 叙事中插入 1-2 句"你记得……"，引用过去的选择
   → 覆盖：全部 22 章，每章约 30 字

D. 隐藏线索（宝藏）
   → 每章 1-2 个彩色可点文字 → 获得跨章道具 → 解锁后续隐藏选项
   → 覆盖：全部 22 章
```

## 二、数值体系：双轴 × 三层宿命

### 2.1 双轴定义

| 轴 | 含义 | 文学原型 | 对应系统 |
|----|------|---------|---------|
| **宿命（Fate）** | 顺从命运 vs 反抗命运 | 奥雷里亚诺上校：打三十二场败仗仍然活着——这是服从还是反抗？ | `fateCounter`（每章重置）+ `fateImprint`（永久） |
| **羁绊（Bond）** | 与家族/他人的连接强度 | 乌尔苏拉：用一生在桌上摆碗筷——这是牢笼还是锚？ | `bondCounter`（每章重置）+ `bondImprint`（永久） |

### 2.2 四象限

```
          高羁绊 ↑
                │
   家族守望者    │    命运追随者
   (为家人而活)  │    (理解一切，仍选择连接)
                │
   ─────────────┼─────────────→ 高宿命
                │
   孤独反抗者    │    孤绝先知
   (搏斗命运，   │    (看透一切，
    独自一人)    │     与谁都不相连)
                │
          低羁绊 ↓
```

象限决定：结算叙事变体、角色对话语气、终局。
**不是 4 个结局，是 4 种阅读体验。**

### 2.3 三层宿命体系

| 层级 | 存储 | 重置？ | 作用 |
|------|------|:---:|------|
| **章节值** | `fateCounter` / `bondCounter` | ✅ 每章重置 | 本章叙事变体、章末判定档位 |
| **动量** | 上章档位 → 下章起始值 | 自动传递 | 制造连续性——惯性。规则：见证者 → 下章起始 = 最大值的 2/3；追随者 → 起始 = 1/3；抗争者 → 起始 = 0 |
| **烙印** | `fateImprint[chapterNum]` / `bondImprint[chapterNum]` | ❌ 永久 | 终局条件、成就、跨章回声触发 |

### 2.4 关系值（与双轴的区别）

| 维度 | 双轴（fate/bond） | 关系值 |
|------|-----------------|--------|
| 作用对象 | 你的整体倾向 | 你与**特定角色**的关系 |
| 粒度 | 每人 0-100 | 每角色 0-100 |
| 重置 | 每章重置值 | 永久不重置 |
| 质变 | 章末判定档位 | 阈值 30/70/85 触发隐藏对话/剧情 |
| 体现 | 结算标签、象限 | 对话内容变化、秘密披露、关键时刻行为 |

## 三、收集体系

### 3.1 三种收集物的分工

| 类型 | 触发方式 | 获得什么 | 可用来做什么 |
|------|---------|---------|------------|
| **记忆碎片** | 做出特定选择后自动获得 | 一段情节摘要 | 收集、解锁成就、部分碎片可解锁隐藏选项 |
| **隐藏线索** | 叙事中点击彩色文字 | 一个线索道具 + 一段隐藏叙事 | 跨章节解锁隐藏选项 |
| **探索热点** | 探索场景中点光点 | 一段场景叙事 | 仅当期场景探索体验 |

### 3.2 隐藏线索的渲染规则

- 线索文字颜色比正文略偏暖（`#8a6040`，正文为 `#1a0f08`）
- hover 时变色（`#b8893e`），暗示可点击
- 点击后弹出小型卡片：线索名称 + 一段叙事
- 已发现的线索文字变灰，不可重复点击
- 线索道具存入 `GameState.clueFragments[]`，跨存档持久化
- 历史档案面板新增"隐藏线索"分类

### 3.3 记忆碎片的"钥匙"功能

部分记忆碎片带有 `unlockHint` 和 `unlocksIn` 字段：
- `unlockHint`：一句提示，告诉玩家此碎片在何处有额外作用
- `unlocksIn`：数组，列出此碎片在哪些章节能解锁隐藏选项
- 拥有碎片后，在目标章节的选择场景中会出现带 `requiredMemory` 的隐藏选项

类似地，隐藏线索通过 `requiredClue` 字段在后续章节解锁选项。
